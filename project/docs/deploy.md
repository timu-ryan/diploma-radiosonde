# Развёртывание

Все команды — в корне репозитория на сервере.

## 1. Настройки (`.env`)

`.env` нужен до сборки: из него берётся `BASE_PATH`.

```bash
cp .env.example .env
chmod 600 .env
```

Минимум для боевого сервера:

```bash
# За Apache/nginx — только локально; без прокси — 0.0.0.0
HOST=127.0.0.1
PORT=3001
# Сайт открыт не в корне домена: https://aviametserver.ru/zond/
BASE_PATH=/zond/

DB_URL=mysql://rs_site:<пароль>@127.0.0.1:3306/rs_site
# Свой для боевого сервера и постоянный: openssl rand -hex 32
SESSION_SECRET=<64 hex-символа>
# Только если сайт открыт по https
COOKIE_SECURE=1

AVIAMET_TOKEN=<токен aviametserver.ru>
# AVIAMET_KEEP_RUNS=2
```

- `BASE_PATH` попадает в сборку фронтенда: поменяли — заново `npm run build`. Если сборка
  не совпадает с `.env`, сервер пишет в лог «Фронтенд собран не под BASE_PATH».
- Спецсимволы в пароле внутри `DB_URL` кодируются как в URL: `@` → `%40`, `:` → `%3A`, `/` → `%2F`.
- Без `SESSION_SECRET` ключ сессий случайный — после каждого перезапуска всем придётся входить заново.
- `COOKIE_SECURE=1` на сайте без https ломает вход: браузер не сохранит cookie.
- `.env` ищется в корне репозитория по расположению кода, а не в текущем каталоге. Переменные,
  заданные в окружении (например, `Environment=` в systemd), главнее `.env`.
- Остальные настройки — в README, раздел «Переменные окружения».

## 2. Сборка

```bash
npm ci
npm run build                       # shared → server → web, порядок важен
```

Ставьте зависимости **полностью**, без `--omit=dev`: TypeScript и Vite нужны для сборки,
`tsx` — для `npm run user`.

## 3. Первый администратор

```bash
npm run user -- admin --admin --coords --fio "Иванов И. И."
```

Пароль спрашивается в терминале. Если в базе уже есть администратор (база общая
с локальной разработкой) — шаг не нужен.

## 4. Пробный запуск

```bash
npm start
```

В логе должны быть строки «База пользователей: 127.0.0.1:3306/rs_site», «Загружено планшетов
станций: 105», «Фронтенд раздаётся из …» и `Server listening at http://127.0.0.1:3001`.
В соседнем терминале:

```bash
curl -s http://127.0.0.1:3001/api/health
# {"status":"ok","stations":105,"runs":0}   — runs станет > 0, когда скачаются прогоны (≈ 10 с на прогон)
```

## 5. Apache

Сайт под `/zond/` — в конфиг виртуального хоста (модули `proxy`, `proxy_http`):

```apache
ProxyPass        /zond/ http://127.0.0.1:3001/zond/
ProxyPassReverse /zond/ http://127.0.0.1:3001/zond/
RedirectMatch    ^/zond$ /zond/
```

Можно и срезать префикс (`http://127.0.0.1:3001/`) — сервер принимает оба вида.
Снаружи проверка — `https://aviametserver.ru/zond/api/health`.
